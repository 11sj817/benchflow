# BenchFlow UI 设计系统

版本：2.0
定位：Professional · Industrial · Clean · Precise · Data-driven

参考成熟研发管理软件的信息架构与信息密度（Linear / Jira / GitLab / TestRail 的交互模式），不复制任何品牌视觉。

---

## 1. 布局

### PC（主场景）

| 区域 | 规格 |
| --- | --- |
| 左侧主导航 | 236px，深色 `#14202e`，可折叠至 62px |
| 顶部工具栏 | 56px，白底 1px 下边框 |
| 内容区 | 自适应，`padding: 20px 24px 32px` |
| 详情页 | 左右分栏：主内容 `minmax(0,1.6fr)` + 侧栏 `minmax(300px,0.85fr)` |
| 抽屉 | 设备 / 数据集 / 版本 / 需求追踪，右侧滑出 |
| 断点 | 1440 为主设计尺寸；1920 保持左侧信息密度；1366 使用 `compact` 密度与两列 KPI；≤960 侧栏变抽屉 |

### 移动端

独立 `MobileLayout`：顶部 52px 深色栏 + 内容 12px 内边距 + 底部 5 Tab（中间“记录”凸起按钮）。内容最大宽度 460px，居中模拟手机；真实设备全宽。

### 平板工位

`StationLayout`：62px 顶栏 + 主区两栏（执行区 / 设备与环境区）。触控目标 ≥ 40px，输入框 `size="large"`。

## 3. 字体与数字

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC',
  'Hiragino Sans GB', 'Microsoft YaHei', Arial, sans-serif;
```

| 层级 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| 页面标题 | 19–21px / 650 | 页面 h1、详情标题 |
| 面板标题 | 13.5px / 600 | `bf-panel-header h2` |
| 正文 | 13px / 400 | 默认 |
| 表格 | 12.8px | 高密度列表 |
| 辅助 | 11.5–12px / 400 | 编号、说明、次级信息 |
| KPI | 24px / 620 | `.bf-kpi .value` |
| 等宽 | 12px | 编号、参数、限值（`--bf-mono`） |

## 4. 间距与圆角

- 间距序列：4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24 / 32。
- 页面区块间距 14px；面板内边距 16px；表格单元格默认 Element Plus 紧凑模式。
- 圆角：控件 5px，面板 8px，标签 999px。
- 阴影：`0 1px 2px rgba(20,32,46,.06)`；浮层 `0 8px 24px rgba(20,32,46,.1)`。

## 5. 组件规范

### 5.1 面板

```text
.bf-panel
  .bf-panel-header（48px，标题 + 右侧操作/计数）
  .bf-panel-body（16px；表格用 flush）
```

页面不要把所有数据都包成卡片。KPI 用 4 列指标条，列表用表格，详情用描述列表 + 步骤列表。

### 5.2 状态标签

`.bf-pill` + tone：`primary / success / warning / danger / info / neutral`，可带 6px 圆点。所有状态统一由 `utils/format.ts` 字典输出，禁止各页面自定义颜色。

### 5.3 表格

- `size="small"`，表头背景 `#f7f9fc`，行 hover `#f6f9fd`。
- 编号列用 `.bf-table-code`（等宽、主色）；名称列首行加粗 + 次行说明。
- 排序：`sortable="custom"` + `useTable` 的 `onSortChange`；分页由 `DataPager` 统一。
- 操作列固定右侧，最多 2 个文字按钮 + “更多”下拉。

### 5.4 表单

- 标签宽 92–110px，右对齐；两列栅格仅在 ≥760px 使用。
- 必填校验使用 Element Plus `rules`，并在提交前做业务校验（阈值、日期、备注）。
- 长文本使用 textarea + `show-word-limit`；危险操作二次确认。

### 5.5 抽屉 / 对话框

- 快速查看用抽屉（620px / 560px）；创建/编辑用对话框（480–760px）。
- 抽屉头部固定、底部操作固定；表单在抽屉内不嵌套过长。
- 删除、恢复演示数据等不可逆操作必须 `ElMessageBox.confirm`，文案说明后果。

### 5.6 图表

- 统一 `BaseChart`，高度 200 / 260 / 320。
- 网格线 `#eef2f7`，坐标文字 9–10px `#8494a8`，图例小方块。
- 状态色：PASS `#2f7f6b`、FAIL `#b02a1f`、主趋势 `#1e3a5f`。
- 图表必须与筛选条件联动；无数据显示 EmptyState，不生成随机数据。

## 6. 交互模式

1. 所有导航真实跳转；面包屑显示模块 + 当前页。
2. 全局搜索覆盖项目 / 用例 / 执行 / 缺陷 / 报告（访客仅项目与报告）。
3. 通知气泡：未读计数、单项已读、全部已读、跳转。
4. 身份切换：顶部用户菜单 → 演示身份/角色对话框，明确“非生产级认证”。
5. 数据状态：侧栏底部“本地演示模式” + 数据修订号；顶部横幅说明限制。
6. 空状态：说明为什么为空 + 下一步动作按钮。
7. 禁用按钮保留可见，并在就近位置说明原因（如“仅组织管理员可修改”）。

## 7. 响应式

| 宽度 | 行为 |
| --- | --- |
| ≥1440 | 四列 KPI、双列图表、详情双栏 |
| 1280–1439 | KPI 两列、详情单栏、图表单列 |
| 960–1279 | 侧栏保持但搜索收窄；表格横向滚动 |
| ≤960 | 侧栏抽屉、隐藏模块面包屑与搜索、隐藏次要文字 |
| ≤760 | 表单单列、模板卡单列 |
| ≤640 | 报告指标两列、分享页元信息单列 |

移动端不得出现横向溢出；表格使用 `overflow-x: auto`，图表容器 `min-width: 0`。

---

## 8. 可访问性与打印

- 正文对比度 ≥ 4.5:1（`#54637a` on `#fff` 约 6.3:1）。
- 所有图标按钮带 `title` 或可见文字；焦点环由 Element Plus 提供。
- 打印：隐藏侧栏、工具栏、抽屉与遮罩，仅保留 `.print-area`；报告文档去除边框与阴影，章节 `break-inside: avoid`。
- 打印页面使用组织名 + 报告编号 + 页脚声明，保证可归档。

---

## 9. 文案规范

- 编号与参数使用等宽字体，例如 `RUN-0017`、`≤ 50 mV`。
- 不使用“AI 驱动”“颠覆”等营销词。
- 限制必须写清楚：本地演示 / 模拟 / 待接入后端，不用“云端同步成功”等误导文案。
- 错误提示给出原因与下一步，例如“该用例已被 TP-2401-01 引用，不能删除，建议改为已停用”。

---

## 10. 设计变量落点

- `src/styles/tokens.css`：颜色、字体、圆角、Element Plus 映射。
- `src/styles/global.css`：布局、面板、KPI、表格、标签、打印、响应式。
- 页面内 scoped 样式只允许布局微调，不得重新定义主色与字号体系。
